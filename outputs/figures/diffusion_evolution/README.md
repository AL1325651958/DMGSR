# 扩散模型过程演化图

本图回答：固定缺测案例的重建场如何演化，以及变化是否伴随误差下降。

## 阅读顺序

- `diffusion_evolution.gif`：初始含噪隐变量 → 每 8 步分块输出 → 最终后处理；参考值固定，重建与误差逐阶段更新。
- `diffusion_evolution_overview.png`：高清中文总览；同名 PDF、SVG 可缩放查看。
- `stage_metrics.csv`：全部阶段的 RMSE、MAE、CRPS、90% 集合覆盖率和区间宽度。
- `source_data.npz`：真实采样轨迹、参考值、掩码及初始隐变量。
- `metadata.json`：随机种子、模型指纹和实验条件。

## 案例与边界

固定采用 2011 年 7 月，中央 4×4 网格在 9–15 日连续缺测。展示日固定为缺测中间日 12 日，并非按误差挑选。模型采用训练种子 11 的图约束扩散检查点；采样种子为 20260911，共 12 个集合成员，64 步反向去噪。没有重新训练，没有加入 U-Net 融合或额外集合校准。

各分块输出已包含采样器中的月约束和图边界反馈，因此不应视为纯神经网络去噪消融。最后一阶段另含空间后处理。初始图为第一个成员的标准化隐变量，后续辐射图为 12 成员的均值，二者单位和统计含义不同，不能直接比较初始噪声图与辐射色标。

参考是 NASA POWER 卫星/再分析派生产品，不是独立站点实测。月条件由完整参考产品计算，包含被遮蔽数据的信息；这是已知月条件下的受控恢复。采用 31 天的七月避免已知短月份月约束偏差，不能据此认为该缺陷已经修复。

误差指标使用全部 7×4×4=112 个缺测日-网格值，等网格权重；已知区域和无效日期不参与评分。没有以全场已知值稀释缺测误差。地图使用原生网格，无空间插值；所有辐射阶段共享完整色标范围，误差共享对称范围。时间序列先逐成员计算缺测空间块的算术平均，再对成员求均值及 5%–95% 分位区间。区间不是训练种子置信区间。

## 本案例结果

RMSE：第 8 步 48.31 → 第 40 步 42.72 → 第 64 步 44.67 → 最终后处理 37.70 W/m²。

最终 MAE 为 30.44 W/m²，CRPS 为 23.96 W/m²；名义 90% 区间在缺测值上的实际覆盖率仅 44.6%。因此过程后期并非持续改善，最终仍存在偏差和欠覆盖。单案例不能支持总体性能或方法优越性结论。
