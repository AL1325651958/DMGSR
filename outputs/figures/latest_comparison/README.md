# 最新权重的同案例对照

本组图使用最新保存的 8 个 U-Net 成员，结合上一幅过程图的 12 个扩散成员。固定沿用融合权重 0.9 和离散度乘数 6.5，不重新训练、不重新选参数。

## 读图

- `latest_matched_comparison.png`：参考、扩散、U-Net、融合的并排空间图，以及逐日空间平均序列和全部缺测值散点。提供同名 PDF / SVG。
- `latest_error_comparison.png`：同一天三种模型的误差图，固定对称色标，白色附近代表误差小。
- `metrics.csv` / `metrics.json`：所有 112 个缺测值上的 RMSE、MAE、CRPS、90% 集合区间覆盖率与宽度。
- `source_data.npz`：完整成员输出、参考值和掩码。

## 版本与日期

2011 年 7 月，9–15 日中央 4×4 网格缺测，与先前过程图完全一致。空间展示日固定为 12 日，没有按效果挑选。

检查旧 U-Net 集合评估实现时发现，它用验证集局部索引访问完整数据的气象、月条件及太阳先验。2011 年 7 月的验证局部索引为 18，对应完整数据的 2001 年 7 月；正确完整索引应为 138。因此本图使用正确日期重新推理，不能直接视为旧汇总分数的可视化复现。

最新融合参数曾在旧流程输出上选定。本次仅冻结沿用，因此修正日期后的模型仍需重新校准及全报告集评估。这些工作不由本次单案例图替代。原始权重和原始报告未覆盖。

## 数据含义

参考值是 POWER 派生产品，月条件由完整参考计算，包含遮蔽值信息。本图不是独立站点验证。所有方法仅在同样的 112 个缺测日-网格值上评分，空间图共用色标且不插值。已知区域保持参考值。均值和分位区间来自成员输出，并非跨训练种子的置信区间；逐日区间先计算每个成员的缺测空间块平均，再取成员分位数。

融合公式严格沿用最新脚本：均值为 0.9×U-Net 均值＋0.1×扩散均值；将两组按权重缩放的中心化成员残差拼接，乘以 6.5 后加回融合均值。本次未增加原脚本没有的裁剪或投影。

本次采用屏幕阅读尺寸，PNG 为 300 dpi，并提供可编辑文字的矢量 PDF / SVG；静态预检关于投稿尺寸、600 dpi 和 TIFF 的提示不适用于这次屏幕演示交付。布局检查在每次渲染后执行，PDF 碰撞与字号结果保存在同目录。输入参考对齐、有限值、已知值保持和融合均值公式均有数值断言。
