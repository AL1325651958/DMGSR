# Pre-registration: confirmatory evaluation on 2012–2014

Written **before** any 2012–2014 quantity was computed. The purpose is to make
the confirmatory claim falsifiable: the decision rules below are fixed now, and
the outcome is reported against them whatever it is.

## What was already known when this was written

- 2000–2009 was used to fit all network weights.
- 2010–2011 was used for checkpoint selection (diffusion seed 11) and, in the
  reported analysis, for calibration-parameter selection.
- **2012–2014 has never been evaluated in any form.** It contains 36 months,
  all finite, 109 600 valid day–grid values.
- The evaluated checkpoints are `outputs/masked_v9_graph/model_{11,22,33}.pt`
  (diffusion) and `outputs/spatial_unet_ensemble/model_{0..7}.pt` (U-Net).
  No retraining is performed, so nothing about 2012–2014 can influence weights.
- The published 2011 numbers are: Fusion RMSE 19.77, CRPS 11.24; calibrated
  U-Net RMSE 20.84, CRPS 12.34; coverage 93.2% vs 85.4%; widths 81.83 vs 66.11.

## Protocol for the confirmatory run

1. **Checkpoints**: frozen, as listed above. No training, no fine-tuning, no
   seed search.
2. **Calibration period**: **2010 only.** 2011 is *excluded* from calibration
   here, because it was used for checkpoint selection. This differs from the
   published analysis, which calibrated on 2010–2011; the confirmatory run is
   therefore strictly harder and is not a re-run of the published number.
3. **Evaluation period**: all 36 months of 2012–2014.
4. **Masks**: one stored synthetic mask per month, generated by the same
   `random_observation_mask` procedure with identical parameters
   (1–7 day runs, 2–5 cell sides, spatial probability 0.35, mixed mode), with
   the RNG seed fixed before the run so the mask realisation is not chosen
   after seeing scores.
5. **Calibration search**: the published grid and objective, unchanged —
   `w ∈ {0, 0.05, …, 1}`, `γ ∈ {0.5, 0.75, …, 8}`, objective
   `J = CRPS + 8 |C₀.₉ − 0.9|` with CRPS in W/m², minimised on 2010 missing
   cells; the U-Net-only comparator receives the same spread grid and objective.
6. **Metrics**: pooled RMSE, MAE, CRPS, empirical 90% coverage and mean width
   on missing cells only, plus a paired month-block bootstrap over the 36
   confirmatory months (2 000 draws) for fusion minus calibrated U-Net.
7. **Seed reporting**: all three diffusion checkpoints are evaluated and the
   ensemble-mean metrics are reported per seed as well as for the pre-selected
   seed 11, so the confirmatory claim carries a seed spread.

## Decision rules, fixed in advance

| Claim | Confirmed if | Partially confirmed if | Not confirmed if |
|---|---|---|---|
| **C1** Fusion beats calibrated U-Net on point accuracy | paired bootstrap interval for ΔRMSE lies entirely below 0, **and** the point estimate is ≥ 2% better | interval entirely below 0 but improvement < 2% | interval includes 0 |
| **C2** Fusion improves reliability over raw ensembles | fusion coverage within [0.87, 0.93] | within [0.85, 0.95] | outside [0.85, 0.95] |
| **C3** The coverage gain is not bought purely by widening | fusion CRPS < calibrated-U-Net CRPS | equal within 0.5% | fusion CRPS worse |
| **C4** Raw ensembles are underdispersed (replicates on new data) | raw coverage < 0.70 for both neural branches | < 0.80 | ≥ 0.80 |

No claim is upgraded because of a favourable subgroup. If C1 fails, the paper's
headline comparison is reported as not confirmed on independent data, and the
2011 result is relabelled as a development-period result.

## What this design still cannot establish

- The monthly condition is built from the complete reference product, so it
  carries information about the hidden values in 2012–2014 as well. The
  confirmatory run tests **replication on new data**, not removal of that
  information.
- Only one mask realisation per month. The bootstrap resamples months, so it
  describes among-month variability, not gap-to-gap variability.
- POWER is a derived product; agreement is within-product recovery.
