# 论文初稿交付说明

本目录沿用原稿的 Solar Energy / Elsevier 排版，完成英文初稿及 8 张实际配图。Windows 中 `paper` 与 `Paper` 指向同一目录。

## 阅读入口

- `Manuscript.pdf`：包含正文、公式、结果表、8 张图和参考文献的阅读版。
- `Manuscript.tex`：主稿；`Manuscript_draft.tex` 为相同内容的初稿副本。
- `figures/all_figures_preview.png`：8 张图总览。
- `figures/Fig01` 至 `Fig08`：每张均提供 PDF、SVG 和 300 dpi PNG，图中字体可编辑。
- `original/Manuscript_received.tex`：收到的原稿备份。
- `evidence/results.json`、`monthly_metrics.csv`：正文数值来源。

## 本次完成的实质修订

1. 核对实际实现，改写为固定四邻域图正则化、卷积 U-Net、扩散采样与经验校准；删除未实现的图注意力、风向自适应连边及无实验依据的消融结论。
2. 重新对齐 U-Net 的绝对年月索引，并在本次扩散评估中修正短月份的能量目标。修正位于 `build_evidence.py` 的局部评估流程，未声称原始训练流程已全部修复或模型已重新训练。
3. 使用同一批缺测掩码比较方法，2010 年选择校准参数，2011 年汇总 547 个缺测日—网格值。另行校准 U-Net 的区间宽度，避免只给融合模型校准机会。
4. 融合结果 RMSE 为 19.77 W/m²，CRPS 为 11.24 W/m²；校准 U-Net 对应为 20.84 和 12.34。90% 区间覆盖率分别为 93.2% 和 85.4%，融合区间也更宽。
5. 保留真实扩散过程和七天案例，明确其为单例，不能代替全年汇总结果。

## 证据边界与待填信息

这是一份完成写作与配图的研究初稿，不是已经满足投稿证据要求的定稿。2011 年此前被开发过程查看，不能称为独立测试集；月度条件由完整参考场提供，含隐藏值的信息；尚无严格匹配的图正则化消融；融合样本有约 0.95% 负值。这些限制已在摘要、方法和讨论中说明。

作者姓名、单位、通讯作者、贡献、基金、利益冲突及永久数据/代码仓库需要作者提供。没有虚构这些信息。正式投稿前还需作者审核全部技术描述和引用，并补充独立区域/时期验证与消融实验。

## 复现

在项目根目录运行 `python paper/build_evidence.py` 可由已保存的对齐集合重新计算校准和指标；删除或改名缓存后重新推断还需原项目数据及权重。运行 `python paper/make_figures.py` 重画八张图；图的源数据已存入 `paper/evidence`。绘图依赖本机 nature-figure 技能的面板检查模块。

在本目录运行 `tools/tectonic.exe --keep-logs Manuscript.tex` 编译。首次编译会下载官方 TeX 资源。
