# Supplementary figures and result audit

This directory holds figures that are **not** part of the eight-figure manuscript
plus the scripts that re-derive every numeric claim in `../Manuscript.tex`.

## Deliverable

`DMGSR_missing_figures.pptx` — three editable slides, drawn with native
PowerPoint shapes and text (no embedded images, so every label stays editable):

| Slide | Content |
|---|---|
| 1 | Gap regime schematic: the four artificial-missingness families the manuscript defines but never depicts |
| 2 | Chunk-boundary correction sequence: what actually runs during reverse sampling, in code order |
| 3 | Graph-regularization ablation: four matched configurations, the factors held fixed, and their results |
| 4 | Provenance, intended placement, and the omissions a drawing cannot close |

`DMGSR_missing_figures.pdf` and `preview_pdf/` are renders for inspection only.
Rebuild with the bundled Python:

```powershell
& $env:DSH_PYTHON paper/make_missing_figures.py
```

Slide 3 fills its results panel automatically from
`outputs/ablation_graph/ablation_results.json`; until all four configurations
have finished it shows a pending notice instead of numbers.

## Graph-regularization ablation

```powershell
$env:PYTHONPATH = "src"
python -m dmgsr.ablation --epochs 30 --seeds 11 22 33 `
  --train-spatial-probability 0.8 --missing-weight 5.0 --gradient-weight 0.08
python -m dmgsr.ablation_report
```

Four configurations differ only in the graph mechanism: the four-neighbour
structural penalty in the training loss and the two inference-time graph
operations (chunk-boundary correction, final spatial blends). Data, chronological
split, mask schedule, fitting seeds, epoch count and checkpoint selection are
identical. The trajectory weights above are the values recorded in
`outputs/masked_v9_graph/protocol.json`, so the `full` configuration reproduces
the evaluated model rather than the current code defaults.

Artifacts: `outputs/ablation_graph/<config>/model_<seed>.pt`,
`ensemble_*_seed<seed>.npz`, `ablation_results.json` (the selected seed per
configuration), `per_seed_results.json` and `REPORT.md`.

The gap patterns are regenerated by a NumPy transliteration of
`dmgsr.masked_temporal.random_observation_mask` with the documented parameters
(1–7 day runs, 2–5 cell sides, 0.35 spatial probability), so the drawn patterns
are reproducible rather than illustrative. The transliteration is used only so
the figure script runs without PyTorch.

## Audit scripts

| Script | Scope |
|---|---|
| `../audit_numbers.py` | Table 1, the narrative deltas, the bootstrap interval, the selected calibration parameters, the negative-value count |
| `../audit_figures.py` | Figure 8 trajectory, Figures 3–4 pooled skill and reliability, Figure 6 monthly RMSE, Figure 7 case size |
| `../audit_monthly.py` | Per-month RMSE against `evidence/monthly_metrics.csv`, three ways |

All three are read-only. They recompute from `../evidence/` and print a pass
summary; they do not rewrite any evidence file.

## Result

53 numeric claims reproduced, 0 mismatches. The three omissions reported on
slide 3 are experiment-level, not drafting-level: a controlled
graph-regularization ablation, independent validation on a period or region
that development never inspected, and a sensitivity analysis of the monthly
condition. Each needs new training or inference runs and must not be replaced
by a drawn figure.
